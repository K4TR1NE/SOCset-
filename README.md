## 🚀 Быстрый старт

### Системные требования

- **Python** 3.9 или выше
- **pip** (менеджер пакетов Python)
- **Git** (опционально, для клонирования)

### Установка

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/yourusername/vega-social.git
cd vega-social

# 2. Создайте виртуальное окружение (рекомендуется)
python -m venv venv

# 3. Активируйте виртуальное окружение
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# 4. Установите зависимости
pip install flask werkzeug

# 5. Запустите приложение
python app.py
```

### Откройте в браузере

```
http://192.168.1.17:5000
```

> 💡 **Примечание**: При первом запуске автоматически создадутся все таблицы базы данных и предустановленные праздники.

## 🗄️ База данных

### Схема базы данных

```sql
users           # Пользователи (телефон, пароль, имя, аватар, знак зодиака, статус, is_guest)
posts           # Посты (текст, автор, лайки, комментарии, репосты, привязка к стене)
friends         # Дружеские связи (user_id, friend_id, status: pending/accepted)
messages        # Личные сообщения (от кого, кому, текст, прочитано, is_repost, repost_post_id)
likes           # Лайки на постах (user_id, post_id)
comments        # Комментарии (user_id, post_id, текст)
gallery         # Медиафайлы (user_id, путь, тип, описание, post_id)
events          # События (название, дата, тип: holiday/personal, цвет, иконка)
user_settings   # Настройки (тема, размер шрифта, приватность, уведомления)
```

| **TinyMCE** | Визуальный редактор постов |

### Особенности реализации
- 🔐 **CSRF-защита** всех форм
- 📁 **Безопасная загрузка** файлов (проверка расширений и размера)
- 🌙 **Светлая/тёмная тема** с сохранением в localStorage и БД
- 📱 **Адаптивный дизайн** для мобильных устройств
- 👤 **Гостевой режим** без регистрации
- 🔄 **Репосты** на стену и другу (с карточками в чате)
- 🖼️ **Просмотр фото** в модальном окне с навигацией стрелками

## 📡 API Маршруты

### Основные маршруты

| Метод | Маршрут | Описание |
|:------|:--------|:---------|
| `GET` | `/` | Главная лента |
| `GET/POST` | `/login` | Вход (телефон + пароль / гость) |
| `GET/POST` | `/register` | Регистрация |
| `GET` | `/logout` | Выход из аккаунта |
| `GET` | `/profile` | Личный профиль |
| `GET` | `/user/<id>` | Профиль пользователя |

### Посты и взаимодействие

| Метод | Маршрут | Описание |
|:------|:--------|:---------|
| `POST` | `/create_post` | Создание поста |
| `POST` | `/like_post/<id>` | Лайк/анлайк поста |
| `POST` | `/add_comment/<id>` | Добавление комментария |
| `GET` | `/get_comments/<id>` | Получение комментариев |
| `POST` | `/delete_post/<id>` | Удаление поста |
| `POST` | `/edit_post/<id>` | Редактирование поста |

### Репосты

| Метод | Маршрут | Описание |
|:------|:--------|:---------|
| `POST` | `/create_repost` | Репост на свою стену |
| `POST` | `/send_repost_to_chat` | Репост другу в чат |
| `GET` | `/get_post/<id>` | Получение поста для карточки |

### Друзья и чат

| Метод | Маршрут | Описание |
|:------|:--------|:---------|
| `GET` | `/friends` | Страница друзей |
| `POST` | `/send_friend_request/<id>` | Отправка заявки |
| `POST` | `/accept_friend_request/<id>` | Принять заявку |
| `POST` | `/remove_friend/<id>` | Удалить из друзей |
| `GET` | `/chat` | Страница чата |
| `POST` | `/send_message` | Отправка сообщения |
| `GET` | `/get_messages/<id>` | Получение сообщений |

### Галерея и события

| Метод | Маршрут | Описание |
|:------|:--------|:---------|
| `GET` | `/gallery` | Страница галереи |
| `POST` | `/upload_to_gallery` | Загрузка в галерею |
| `POST` | `/delete_gallery_item/<id>` | Удаление из галереи |
| `GET` | `/events` | Календарь событий |
| `POST` | `/add_event` | Добавление события |

### Настройки и поиск

| Метод | Маршрут | Описание |
|:------|:--------|:---------|
| `GET` | `/settings` | Страница настроек |
| `POST` | `/save_settings` | Сохранение настроек |
| `POST` | `/change_password` | Смена пароля |
| `GET` | `/search` | Поиск пользователей |
